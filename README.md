# selection-and-loops-python
Academic exercises and activities focused on selection and loop structures using Python.

A collection of academic exercises and activities developed in Python to practice selection and loop structures.<br>

The activities were created as part of my programming studies, focusing on decision-making, repetition, and program flow control.<br>

About the Project<br>

This repository contains exercises involving conditional statements and loops, exploring different ways to control the flow and execution of Python programs.<br>

The goal is to develop a better understanding of how programs can make decisions and perform repetitive tasks based on specific conditions.<br>
